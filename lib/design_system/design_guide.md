## 파일 사용 범위

- app_colors.dart: HEX 색과 명시된 투명도. 의미가 없는 secondary/success 색은 만들지 않음.
- app_text_styles.dart: 명시된 서체·크기·굵기·자간·가변 폭. 생략된 속성은 미확정.
- app_spacing.dart: 간격 척도와 화면별 여백.
- app_radius.dart: 다섯 모서리 값과 BorderRadius 상수.
- app_shadows.dart: 확인 가능한 지도 버튼 그림자 offset·blur·opacity만 보존.
- app_component_metrics.dart: 선·아이콘·버튼·카드 등 치수.
- app_motion.dart: 전환 시간과 명시된 Cubic 곡선.
- app_theme.dart: 알려진 전역 값만 묶은 부분 ThemeData. 적용하지 않음.

ThemeData는 const 생성자가 없어 AppTheme.dark만 static final이다. 나머지 토큰은 static const다. Flutter가 채우는 ThemeData의 미지정 값은 가이드에서 추출한 값이 아니다. 완성된 전체 ColorScheme·TextTheme나 모든 컴포넌트 상태 테마로 간주하지 않는다. ThemeData의 primaryColor 지정도 모든 Material 컴포넌트의 ColorScheme을 정의하는 것은 아니다.

## 아이콘·마커·로고 (S05, S06B)

정확한 벡터 path와 아이콘 라이브러리는 제공되지 않았다. 임의의 Material Icons로 매핑하지 않았다.

로고 경로 마크는 출발 링 → 주황 곡선 → 도착 점. 한글 로고는 홈·앱 내부, 영문 워드마크는 시작·로그인·커버. 워드마크에는 구간 기록을 닮은 세 줄 기호를 함께 사용. 앱 아이콘은 검정 바탕에 마크 하나, 내보내기 1024·180·120.

## 사용자 흐름과 인터랙션 (S14)

앱 시작 → 로그인(로그아웃 상태), 또는 홈(로그인 상태, 1.9초).
로그인 → 회원가입1 → 회원가입2 → 회원가입3 → 가입 완료 → 홈. 로그인 성공도 홈.
홈 → 러닝 시작 → 카운트다운 → 실시간 GPS 러닝 ↔ 일시정지 → 종료 확인 → 종료하고 저장 → 러닝 결과.
실시간 러닝에서도 종료 확인으로 바로 이동할 수 있음. 결과 → 경로 상세 → 지도 상세. 결과에서도 지도 크게 보기.
탭: 홈 / 러닝 기록 목록 / 내 정보. 기록 목록 ↔ 달력, 기록 행·날짜 선택 → 기록 상세 → 지도 상세. 내 정보 → 설정, 로그아웃 → 로그인.

| 전환 | 트리거·효과·시간 |
| --- | --- |
| 앱 시작→홈 | 자동 1.9초 후, 페이드아웃 + 1.04배, 250ms |
| 홈→러닝 시작 | 러닝 시작 탭, 아래에서 올라오기300ms |

| 결과→경로 상세 | 자세히 보기, 푸시320ms |

푸시·슬라이드: cubic-bezier(0.2,0,0,1). Smart Animate: ease-out. 디졸브: linear.
지도 제스처: 두 손가락 확대·축소, 한 손가락 이동. 러닝 데이터 카드를 아래로 밀면 한 줄 요약(5.24 km · 32:15 · 6′12″/km)으로 축소. 화면 가장자리를 밀면 뒤로 이동. 드래그 임계값·축소 높이·플랫폼별 뒤로가기 동작은 없음.

## 불명확한 항목

1. 04 타이포그래피와 07–13 화면별 원본 시안이 없음. 전체 화면 배치·모든 텍스트 스타일은 확정 불가.
2. 본문·제목·숫자의 정확한 굵기 대부분, 모든 행간, 일반 자간, 로고·워드마크 크기 미제공. 명시 속성만 부분 TextStyle로 저장.
3. 원칙의 라벨 1/8과 컴포넌트의 고정 라벨12–13·단위22, 히어로112·실시간56–72는 역할별 값으로 보존. 적용 우선순위 미정.
4. 영문 범위: 원칙은 워드마크와 시작·로그인·회원가입의 큰 제목만 허용하지만 입력 가이드는 ID·EMAIL 영문 라벨을 별도 지정. 둘 다 보존, 임의 통일하지 않음.
5. 경로 외곽선: S03은 경로+5px·92%, S05는 검정8px·85%. 서로 다른 값이며 단일 상수나 완성 경로 스타일로 확정하지 않음. 경로 밑 주황 빛의 blur·opacity도 없음.
6. 지도 버튼 그림자 색상·spread·여러 그림자 여부 미제공. app_shadows.dart는 수치만, BoxShadow 없음. 다른 카드·시트 그림자도 미제공.
7. 주황 버튼·마커·토글의 '검정', 흰 버튼 눌림색, 대부분의 비활성 색·불투명도는 정확한 HEX 없음. 이미지 픽셀을 샘플링하거나 추측하지 않음. 지도 버튼94%와 route/soft16%만 명시된 투명도.
8. 별도 secondary 브랜드색·success·warning 팔레트, 라이트 모드, 전체 ColorScheme 없음. 오류색은 입력 전용이므로 전역 오류색으로 확대 적용하지 않음.
9. 버튼 높이: 레이아웃의 러닝 카드54와 컴포넌트60/64·52/56은 개별 역할 값으로 보존. 텍스트 버튼40과 최소 터치44의 조정 방식 없음. 테두리 버튼 높이·패딩, 세그먼트/칩 크기별 역할 배정도 미제공.
10. 모든 버튼 pill999 규칙과 시작 슬래브28 규칙은 후자의 명시 사례를 별도 보존. 체크박스는 토글과 같은 섹션이나 자체 치수는 미제공.
11. 반응형의 기기별 안전 영역은 예시이며 고정값으로 적용하지 않음. 하단 카드26이 안전 영역을 포함하는지, 기기 사이 보간, 지도 우측 버튼 inset, 데이터 카드 높이·투명도, 지도 가시영역 계산법 미제공.
12. 지도 확대 수준·타일 공급자·스타일 JSON, 도로 색 범위의 단계, 아이콘 벡터·에셋·라이브러리 없음. 임의 라이브러리 연결 안 함.
13. 날짜 표기: 원칙의 목록 '9월 28일 (월)'과 목록 컴포넌트의 '9월 28일 월요일'이 다름. '러닝 상세 기록'·'러닝 경로 상세' 등 화면 명칭의 구분도 상세 시안 필요.
