# 2차 업데이트 목록

1차 출시에서 미루고 2차 업데이트에서 할 일을 모아 둡니다. 항목마다 무엇을, 왜 미뤘는지와 다시 할 때 할 일을 적습니다. 결정의 자세한 배경은 [MEMORY.md](../MEMORY.md)의 같은 날짜 항목에 있습니다.

새로 미루는 일이 생기면 여기에 추가하고, 2차에서 끝낸 항목은 지우지 말고 `(완료 YYYY-MM-DD)`를 붙입니다.

## 1. 친구 탭 전체 (2026-11-23) (1차로 되돌림 2026-11-26)
- **2026-11-26**: 사용자 결정으로 1차 출시에 다시 넣었습니다. `FriendsFeature.available = true`, 아래 탭은 홈 · 기록 · 친구 · 룸메이트 · 내 정보 5개(같은 너비). 아래 '다시 할 때' 2번(서버 규칙 확인)은 아직 하지 않았습니다.
- **무엇**: 친구 탭과 거기 딸린 기능 전부. 피드, 응원, 기록·경로 공유, 함께 달리기(대기실, 실시간 위치, 약속 알림 창), 랭킹, 주간 목표.
- **왜**: 실험하고 확인할 것이 너무 많아서 1차 출시 일정에 맞추기 어렵습니다.
- **지금 상태**: 코드는 그대로 두고 화면에서만 숨겼습니다. `FriendsFeature.available = false`([friends_feature.dart](../lib/friends/friends_feature.dart))로 다음이 꺼져 있습니다.
  - 아래 탭의 친구 탭(홈 · 기록 · 내 정보 3개)
  - 함께 달리기 약속 알림 창과 친구 탭 배지
  - 러닝 결과 화면의 '친구에게 공유' 버튼(같은 크기의 빈자리만 남김)
  - 설정 > 계정의 '기록 공개 설정'
  - 러닝 뒤 친구 피드 자동 공유(예전에 켜 둔 사람도 올라가지 않음)
- **계속 동작하는 것**: 공유했던 기록을 지우면 친구 피드에서도 지우기, 러닝을 저장할 때 랭킹용 내 합계를 서버에 올리기(2차에서 랭킹을 켤 때 바로 맞는 값이 나오게).
- **다시 할 때**:
  1. `FriendsFeature.available`을 `true`로 바꿉니다. 숨긴 곳이 모두 다시 나옵니다.
  2. 서버 보안 규칙([firestore.rules](../firestore.rules))의 친구 관련 부분이 그대로 맞는지 확인합니다.
  3. 1차에서 친구 탭 자리에 다른 탭(캐릭터 탭 안)이 들어갔다면 탭 순서를 다시 정합니다([main_tabs.dart](../lib/home/main_tabs.dart)).
  4. 친구 탭 배지 테스트(`test/main_tabs_test.dart`)는 친구 기능이 켜져 있을 때만 돌고, '친구 탭이 없다' 테스트는 꺼져 있을 때만 돕니다.

## 2. 자동 일시정지 (2026-11-23)
- **무엇**: 멈춰 서면 운동 시간을 저절로 멈추고, 다시 달리면 저절로 이어 가는 기능.
- **왜**: 가만히 있어도 자동 일시정지가 다시 풀리는 문제가 있습니다. 1차는 수동 일시정지(화면·잠금화면·워치 버튼)만 씁니다.
- **지금 상태**: `RunningConfig.autoPauseAvailable = false`([running_start_page.dart](../lib/home/running/running_start_page.dart))로 설정 > 러닝의 스위치와 러닝 시작 화면의 버튼을 숨겼고, 폰에 '켜짐'이 저장돼 있어도 자동으로 멈추지 않습니다. 기능 코드, 저장 값, 테스트는 남아 있습니다.
- **다시 할 때**:
  1. 가만히 서 있어도 풀리는 원인을 찾아 고칩니다. GPS가 제자리에서 흔들리는 것을 '움직임'으로 보는 것으로 추정되지만 확인은 안 했습니다.
  2. 밖에서 직접 뛰며 확인합니다. 신호등 대기, 제자리 스트레칭, 천천히 걷기, 실내(GPS 약함)에서 각각 맞게 멈추고 풀리는지 봅니다.
  3. `autoPauseAvailable`을 `true`로 바꿉니다.

## 3. 워치 단독 러닝 (2026-11-13)
- **무엇**: 폰 없이 애플워치만 차고 달리고 기록하기.
- **왜**: 첫 워치 범위를 '폰에서 달리는 러닝을 워치에 보여 주고, 워치에서 일시정지·재개·종료하기'로 정했습니다.
- **다시 할 때**: 워치에서 위치·심박을 직접 재고, 끝난 뒤 폰으로 넘겨 기록으로 저장하는 흐름이 필요합니다. 워치 화면은 SwiftUI로 따로 만듭니다(Flutter는 워치를 지원하지 않음).

## 4. 러닝머신(실내 러닝) (2026-11-23)
- **무엇**: 러닝머신이나 실내에서 달린 거리와 칼로리를 기록하기.
- **왜 지금은 안 되나**: 앱이 GPS로 위치가 움직인 만큼만 거리를 잽니다. 러닝머신에서는 거리·칼로리가 거의 0이고, 칼로리 퀘스트도 오르지 않으며, 경로 없이 점 하나만 남습니다.
- **방법 후보**:
  - 아이폰 걸음 센서로 거리 추정(추천): '실내 러닝' 버튼을 따로 둡니다. 폰을 손에 들거나 거치대에 두면 걸음이 잘 안 잡히고 오차가 GPS보다 큽니다. 아이폰 쪽 코드나 패키지를 추가해야 합니다.
  - 끝난 뒤 러닝머신 화면의 거리를 직접 입력: 가장 쉽지만, 거짓으로 입력해 칼로리 퀘스트를 부풀릴 수 있습니다.
  - 애플워치로 측정: 워치 단독 러닝(3번)이 먼저 있어야 하고, 워치가 없는 사람은 못 씁니다.

## 5. 안드로이드 출시
- **무엇**: 1차는 아이폰만 출시하고, 안드로이드는 2차에 냅니다.
- **남은 일** (2026-10-19 기록 기준이라 지금도 그런지 다시 확인이 필요합니다):
  - 러닝 중 화면이 꺼지면 위치가 끊길 수 있습니다. 포그라운드 서비스와 권한이 필요합니다.
  - 아이폰에만 있는 기능: 음성 안내, 잠금화면 러닝 표시(라이브 액티비티), 기록 목록의 지도 사진(안드로이드는 경로 선만), 워치.
  - 출시용 서명 키를 만들고, 그 지문을 Firebase(구글 로그인용 SHA-1)와 카카오 개발자 콘솔(키 해시)에 추가합니다.
  - Play Console 등록, 개인정보 처리방침, 위치 권한 사용 설명.

## 룸메이트(캐릭터) 탭 (2026-11-26)
- **무엇**: 아래 탭의 룸메이트 탭(햄스터 방 미리보기, 레벨·경험치, 룸메이트 이름 바꾸기).
- **왜**: 사용자 결정으로 숨겼습니다.
- **지금 상태**: 코드는 그대로 두고 탭에서만 뺐습니다. `RoommateFeature.available = false`([roommate_feature.dart](../lib/hamster/roommate_feature.dart)). 아래 탭은 홈 · 기록 · 친구 · 내 정보 4개입니다. 룸메이트 이름은 서버 프로필(`mateName`)에 그대로 있습니다.
- **다시 할 때**: `RoommateFeature.available`을 `true`로 바꿉니다. 탭 테스트(`test/main_tabs_test.dart`)는 스위치에 따라 도는 테스트가 바뀝니다.
